# CHATBOTS · Машины, которые умеют разговаривать

Интерактивный гид о чат-ботах: зачем они нужны, как устроены и как их программируют.
Постраничная навигация жестами + 3D-робот + живой демо-чат.

## Стек

- **HTML5 / CSS3** — разметка, «стеклянные» панели, карточки, адаптив
- **JavaScript (ES-модули)** — пейджер, демо-чат, цикл рендера
- **Three.js / WebGL** — робот: визор, мигающие глаза, рот-эквалайзер, антенна,
  сервисный люк, орбитальные кольца, летающие чат-пузыри
- **Web Audio API** — звуковые блипы чата (отправка / ответ / печать)
- **Edge TTS (нейросетевые голоса)** — бот говорит живыми предсгенерированными MP3;
  голоса-персонажи (Бот / Toxi$ / Swag / Дора) — пародийные пресеты: свой голос, темп,
  паузы и присказки (не реальные голоса артистов). Запасной вариант — системный Web Speech API
- **ИИ на свободных вопросах** — бесплатная модель (Pollinations) через серверный прокси
  `/api/ask`; отвечает в характере выбранного персонажа, озвучка — `/api/tts` на лету
- **Vite** — сборка и dev-сервер

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

## Сборка

```bash
npm run build    # продакшн-сборка в dist/
npm run preview  # предпросмотр сборки на :4173
```

## Главы

| # | Экран | Интерактив |
|---|-------|------------|
| 00 | Интро | параллакс за курсором |
| 01 | Зачем нужны | карточки применения + статистика |
| 02 | Устройство | разборка робота на узлы |
| 03 | Как программируется | 5 шагов пайплайна + поворот 0–360° |
| 04 | Обучение | чипы технологий, материал (пластик/графит), свет |
| 05 | Пинг | кнопка «Отправить пинг» — робот оживает |
| 06 | Демо | чипы + свободные вопросы к ИИ в характере персонажа, нейро-озвучка |

Управление: колесо мыши / свайп / стрелки, PageUp/PageDown, Home/End, навигация 00–06.

## Структура

```
index.html          — разметка глав 00–06
src/
  main.js           — точка входа: UI, цикл рендера, связка модулей
  pager.js          — постраничная навигация (колесо, клавиши, свайпы, хэши)
  scene.js          — Three.js-сцена: сборка робота, свет, анимация деталей
  chat.js           — демо-бот: правила, индикатор печати, задержки
  audio.js          — SoundKit: блипы на Web Audio API
  voice.js          — VoiceBox: воспроизведение реплик (MP3), персонажи, запасной TTS
  poses.js          — ключевые кадры позы робота для глав
  style.css         — дизайн-система и адаптив
scripts/gen-voice.py  — генерация озвучки (Edge TTS): .venv\Scripts\python.exe scripts\gen-voice.py
scripts/test.mjs      — смоук-тест через playwright-core + установленный Chrome
scripts/test-voice.mjs — тест озвучки и переключения персонажей
scripts/test-ai.mjs   — тест свободных вопросов (ИИ + озвучка)
vite.config.js        — мидлвари /api/tts (нейро-озвучка на лету) и /api/ask (прокси к ИИ)
public/
  favicon.svg
  bot-poster.svg    — постер-заглушка, пока грузится WebGL
  voice/            — MP3-реплики персонажей (генерит gen-voice.py)
```
