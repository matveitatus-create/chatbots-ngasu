# CHATBOTS · Чат-боты: как их программируют и где они используются

Интерактивная версия реферата НГАСУ (Сибстрин): каждая глава — слайд презентации,
текст дословно из реферата, по клику на карточку — полный текст раздела.
Постраничная навигация жестами + 3D-робот + живой демо-чат с ИИ.

Авторы: Пустовойтенко Д.А., Татусь М.С. · Руководитель: Тазова П.А. · Новосибирск, 2026.

## Стек

- **HTML5 / CSS3** — разметка, «стеклянные» панели, карточки, модалка, адаптив
- **JavaScript (ES-модули)** — пейджер, демо-чат, модалки с текстом реферата, цикл рендера
- **Three.js / WebGL** — робот: визор, мигающие глаза, рот-эквалайзер, антенна,
  сервисный люк, орбитальные кольца, летающие чат-пузыри
- **Web Audio API** — звуковые блипы чата (отправка / ответ / печать)
- **Edge TTS (нейросетевые голоса)** — бот говорит живыми предсгенерированными MP3;
  голоса-персонажи (Бот / Toxi$ / Swag / Дора) — пародийные пресеты: свой голос, темп,
  паузы и присказки (не реальные голоса артистов). Запасной вариант — системный Web Speech API
- **ИИ на свободных вопросах** — бесплатная модель (Pollinations, `model=openai`).
  Локально сначала серверный прокси `/api/ask` (интернет не дёргаем); на статике —
  сразу все удалённые маршруты параллельно: стриминг ответа, прямой запрос из
  браузера, публичные CORS-прокси (allorigins, codetabs), пауза и повтор. Общий
  дедлайн 25 секунд, при исчерпании бот честно говорит, что связь барахлит.
  Повторные вопросы отдаются из кэша. Отвечает в характере выбранного персонажа;
  озвучка произвольного текста — `/api/tts` на лету (локально), на статике —
  системный синтезатор
- **Vite** — сборка и dev-сервер

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

## Сборка

```bash
npm run build    # продакшн-сборка в dist/
npm run preview  # предпросмотр сборки (с /api/ask и /api/tts)
npx gh-pages -d dist   # публикация в ветку gh-pages
```

## Главы = слайды презентации

| # | Слайд | Интерактив |
|---|-------|------------|
| 00 | 1 · Титул | титульник реферата, параллакс за курсором |
| 01 | 2 · Актуальность и цель работы | карточки → полный текст введения |
| 02 | 3 · Задачи, объект и предмет | шаги задач + карточки → модалки |
| 03 | 4 · Анатомия: три поколения | разборка робота, поколения → модалки §1.1–1.3 |
| 04 | 5 · Стек: 4 уровня на Python | поворот 0–360°, уровни → модалки §2.1–2.4 |
| 05 | 6 · Текстовый интерфейс к BIM | карточки → модалка §3.1 |
| 06 | 7 · PropTech-решения | материал (пластик/графит), свет, разделы → модалки |
| 07 | 8 · Примеры на практике | 4 сценария дословно со слайда → модалки §3.1–3.3 |
| 08 | 9 · Заключение | выводы дословно → модалка заключения |
| 09 | 11 · Спасибо за внимание | ссылка на демо |
| 10 | Демо-чат | чипы + свободные вопросы к ИИ в характере персонажа, нейро-озвучка |

Управление: колесо мыши / свайп / стрелки, PageUp/PageDown, Home/End, навигация 00–10.
Клик по карточке/пункту с ↗ — модалка с полным текстом из реферата (Esc — закрыть).
С клавиатуры карточки доступны тоже: Tab доводит фокус до карточки, Enter/Space
открывает модалку; пока она открыта, Tab циклится внутри, Esc возвращает фокус.

## Тесты и контроль

Нужен установленный Chrome; playwright-core не качает свои браузеры.

```bash
node scripts/test.mjs          # смоук: структура, главы, навигация, слайдеры
node scripts/test-voice.mjs    # озвучка реплик + переключение персонажей
node scripts/test-ai.mjs       # свободные вопросы (ИИ + озвучка) локально
node scripts/test-playback.mjs # ответ ИИ → нейро-озвучка произвольного текста
node scripts/test-live.mjs     # задеплоенный сайт на статике
node scripts/audit.mjs         # замеры: кегли, тач-таргеты, FPS, overflow (1440/768/390)
node scripts/check-a11y.mjs    # клавиатура, фокус, ловушка модалки, демо-чат на мобильном
node scripts/check-console.mjs # консоль при обходе глав и демо-чате
node scripts/check-light.mjs   # слайдер «Свет»: кадры -90/0/+90 различаются
node scripts/check-small.mjs   # крайние форматы: 320x568 и ландшафт 844x390
node scripts/check-stability.mjs # длинная сессия: узлы DOM и куча не растут от переключений
node scripts/check-axe.mjs      # полный WCAG-скан axe-core: все главы на 1440/390/ландшафт, модалка и состояния чата
node scripts/shots-mobile.mjs  # скриншоты мобильной вёрстки
node scripts/shots-chapters.mjs [id...]  # десктоп-скриншоты глав (VW/VH — размер окна)
node scripts/shots-extra.mjs   # модалка (десктоп/мобайл/320), планшет 768, фокус-кольцо карточки
node scripts/shot-og.mjs       # обложка og:image 1200x630 из живой сцены
```

## Структура

```
index.html          — разметка глав 00–10 + модалка реферата
src/
  main.js           — точка входа: UI, цикл рендера, модалки, связка модулей
  pager.js          — постраничная навигация (колесо, клавиши, свайпы, хэши)
  scene.js          — Three.js-сцена: сборка робота, свет, анимация деталей
  chat.js           — демо-бот: чипы + свободные вопросы (цепочка к ИИ)
  docs.js           — полные тексты разделов реферата (модалки по data-doc)
  audio.js          — SoundKit: блипы на Web Audio API
  voice.js          — VoiceBox: воспроизведение реплик (MP3), персонажи, запасной TTS
  poses.js          — ключевые кадры позы робота для глав
  style.css         — дизайн-система, модалка и адаптив
scripts/gen-voice.py    — генерация озвучки (Edge TTS): .venv\Scripts\python.exe scripts\gen-voice.py
scripts/extract-pptx.py — дословное извлечение текста из pptx/docx реферата
scripts/                — тесты и контроль (см. «Тесты и контроль»), скриншоты, обложка og
vite.config.js          — мидлвари /api/tts (нейро-озвучка на лету) и /api/ask (прокси к ИИ)
public/
  favicon.svg
  bot-poster.svg    — постер-заглушка, пока грузится WebGL
  voice/            — MP3-реплики персонажей (генерит gen-voice.py)
```
