# AGENTS.md — chatbots

Гид для ИИ-агента по проекту **CHATBOTS**. Читай это перед любыми правками.

## Что это

Интерактивная веб-версия реферата НГАСУ (Сибстрин) «Чат-боты: как их
программируют и где они используются». Не лендинг и не блог: **каждая глава —
полноэкранный слайд презентации**, переключается жестом (один скролл = один
слайд). В центре — 3D-робот на Three.js, реагирующий на главу; на последнем
слайде — живой демо-чат с ИИ и нейро-озвучка.

Авторы: Пустовойтенко Д.А., Татусь М.С. · Руководитель: Тазова П.А. ·
Новосибирск, 2026.

## Стек

- **Vite 7** — dev-сервер и сборка; в dev/preview поднимает мидлвари `/api/tts` и `/api/ask`.
- **Vanilla JS (ES-модули)** — без фреймворков. Ничего не добавляй (React/Vue и т.п.) без явной просьбы.
- **Three.js ^0.180** — единственная runtime-зависимость.
- **Web Audio API** — блипы чата (`SoundKit`).
- **Edge TTS (Python)** — предгенерённые MP3-реплики персонажей.
- **Pollinations (free)** — ИИ для свободных вопросов, `model=openai`.
- **gh-pages** — публикация `dist/` в ветку `gh-pages`.

## Команды


## Главы = слайды

| # | Слайд | Интерактив |
|---|-------|------------|
| 00 | Титул | титульник реферата, параллакс за курсором |
| 01 | Актуальность и цель | карточки → полный текст введения |
| 02 | Задачи, объект и предмет | шаги задач + карточки → модалки |
| 03 | Анатомия: три поколения | разборка робота, поколения → модалки §1.1–1.3 |
| 04 | Стек: 4 уровня на Python | поворот 0–360°, уровни → модалки §2.1–2.4 |
| 05 | Текстовый интерфейс к BIM | карточки → модалка §3.1 |
| 06 | PropTech-решения | материал (пластик/графит), свет, разделы → модалки |
| 07 | Примеры на практике | 4 сценария дословно → модалки §3.1–3.3 |
| 08 | Заключение | выводы → модалка заключения |
| 09 | Спасибо за внимание | ссылка на демо |
| 10 | Демо-чат | чипы + свободные вопросы к ИИ, нейро-озвучка |

Управление: колесо / свайп / стрелки, PageUp·PageDown, Home·End, навигация 00–10.
Клик по карточке с `data-doc` → модалка с полным текстом реферата (Esc — закрыть).

## Ключевые места в коде

- **Добавить/изменить слайд** — разметка в `index.html` (`<section class="chapter">`),
  поза робота в `src/poses.js` (`POSES_DESKTOP` / `POSES_MOBILE`),
  тексты для модалок в `src/docs.js` (ключ = `data-doc`).
- **Связка навигации** — `src/pager.js`; в `main.js` главы собираются из
  `.chapter` в DOM, активная подсвечивается в `.chapter-nav`.
- **3D-робот** — `src/scene.js`: `lathe()` (тела вращения), `ring()` (торы),
  `flatten()` (склейка мешей по материалу — меньше draw calls). Поза интерполируется
  между ключевыми кадрами через `pose()` из `poses.js` по прогрессу главы.
  Свет тоже задаёт глава: пресеты `LIGHTS` (цвет/интенсивность ключевого и
  контрового, заполнение) интерполируются между слайдами; контактная тень
  `.stage-shadow` в тёмных главах мягче и прозрачнее.
- **Типографика** — шкала 12/14/16/20/28/44 (+ Anton как display). Минимальный
  кегль 12px везде, включая мобильный; `scripts/audit.mjs` следит за этим.
- **Meta** — canonical, `og:*`, `twitter:*` в `index.html`; обложка
  `public/og-cover.png` (1200x630) генерится `scripts/shot-og.mjs` из живой сцены.
  После правок сцены/света/типографики интро обложку обязательно перегенерировать,
  иначе соцсети показывают устаревший кадр (дрейф уже ловили один раз).
- **Футер** — блок «Другие проекты» в главе 10 (`index.html`, `.site-footer` в
  `style.css`): то же стекло, что у карточек; акцент — только hover/focus.
- **Демо-чат** — `src/chat.js`: чипы (`ANSWERS`), `WELCOME`, свободные вопросы.
  Цепочка: на localhost сначала серверный прокси `/api/ask` (интернет не дёргаем),
  на статике — сразу все удалённые маршруты параллельно (стрим, прямой запрос,
  CORS-прокси allorigins/codetabs), пауза и повтор; общий дедлайн 25 секунд,
  при исчерпании — `OFFLINE_ANSWER`. На Pages `/api/ask` и `/api/tts` вообще не
  запрашиваются (`HAS_LOCAL_API` в chat.js и voice.js), озвучка произвольного
  текста там сразу системным синтезатором. Повторные вопросы — из кэша
  sessionStorage. Ответ идёт в характере выбранного персонажа.
- **Озвучка** — `src/voice.js` (`VoiceBox`, 4 персонажа), MP3 в `public/voice/`.
  Персонажи (Бот / Toxi$ / Swag / Дора) — **пародийные пресеты**, не реальные голоса.
  Локально `/api/tts` синтезирует любой текст; на статике — системный `speechSynthesis`.
- **Звуки** — `src/audio.js` (`SoundKit`), выключены по умолчанию.
- **Тексты реферата** — `src/docs.js`, дословно из документа. Правь только при
  явной необходимости; это цитаты, не переписывай «своими словами».

## Правила

1. **Стиль кода** — комментарии и тексты интерфейса по-русски; ES-модули;
   без фреймворков; сохраняй существующий стиль соседних файлов.
2. **Текст реферата не перефразировать** — `docs.js` и тексты на слайдах дословны.
3. **Доступность** — сохраняй `aria-*`, `role`, `skip-link`, `prefers-reduced-motion`.
   Сцена служебная (`aria-hidden`), есть текстовый статус `#scene-status` и
   постер-заглушка `bot-poster.svg`. Карточки с `data-doc` доступны с клавиатуры:
   `role="button"` + `tabindex="0"` (ставит `main.js`), Enter/Space открывает
   модалку. Пока модалка открыта, соседи по `body` получают `inert`, Tab зациклен
   внутри окна, Esc закрывает и возвращает фокус на карточку-триггер.
4. **Мобильная вёрстка** — проверяй `scripts/shots-mobile.mjs`; позы робота
   различаются для десктопа и мобайла (`POSES_MOBILE` + `mobileAnchor`).
   На мобайле фон слайда рисуется подложкой `body::before` ПОД сценой, а текст и
   карточки — НАД ботом (`html.paged .chapter` прозрачные, z-index 3), чтобы бот
   не перекрывал содержимое на узком экране. Палитра глав живёт в переменных
   `--ch-bg` / `--ch-glow` / `--ch-bg-size` на парных селекторах `#id` и
   `body[data-ch]`; атрибут `data-ch` ставит `main.js` при смене главы.
   На планшете (651–900px) колонка чата шире (`min(420px, 58%)`), иначе шапка
   чата переносится по словам. На низких экранах (высота ≤600px, телефон
   ландшафтно) навигация уходит вниз горизонтальной лентой, как на мобайле.
   На 320px: минимум clamp у h2 — 32px, у карточек `overflow-wrap: anywhere`,
   у шагов `flex-wrap: wrap` — иначе длинные слова распирают сетку.
5. **Сеть и API** — на GitHub Pages нет `/api/ask` и `/api/tts`; любую новую
   сетевую функцию делай с запасным путём, работающим на статике.
6. **Секреты не добавлять** — Pollinations бесплатный, ключей в коде нет.
7. **Сборка обязательна после правок:** `npm run build` (и `node scripts/test.mjs`),
   прежде чем говорить «готово». Деплой — отдельным шагом (`npx gh-pages -d dist`).
